DeepSeek WebtoHarness

赋予网页端 AI 真实的本地文件系统与 Shell 操作能力

✨ 核心特性

📂 本地文件直连

基于 File System Access API，AI 能够直接读取、写入、修改和删除你授权的本地目录，告别复制粘贴。

💻 命令自动执行

通过轻量级本地 Node.js 服务，AI 可以执行 CMD/PowerShell 命令，跑测试、编译代码一气呵成。

🛡️ 防封控与自动重试

内置高频请求拦截（冷却机制）与网络异常自动重试（10s 间隔），保障长时间连续调用不被封禁。

🎨 沉浸式 UI 折叠

冗长的 Toolcall 代码块与工具返回结果自动折叠，且左侧配有实时状态图标（运行中/成功/失败）。

⚡ 批量并发优化

支持处理超时保护与写后缓冲，避免文件句柄冲突，彻底解决批次调用时的静默丢包问题。

🔒 安全可控

引入确认弹窗机制。对于危险命令或文件覆盖，用户点击确认后才会执行，且支持一键切换“完全权限”。

🚀 快速开始
  • 准备环境：确保电脑安装了 Node.js 与浏览器插件 Tampermonkey。
  • 启动本地服务：下载下方的 server.js，在该文件所在目录打开终端，运行 node server.js。
  • 安装脚本：下载下方的 用户端脚本.js，新建油猴脚本并粘贴内容，保存。
  • 连接与授权：刷新 DeepSeek 网页，在左侧面板点击“开启模式”，依次选择工作区目录、输入绝对路径和任务目标。
