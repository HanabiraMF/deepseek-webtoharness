1

准备环境

2

下载 server.js 和 start.bat 到同一个目录，双击 start.bat 即可启动（会自动打印访问 Token）。

常见问题

这个工具会消耗 API 额度吗？
完全不会。WebtoHarness 是直接运行在 DeepSeek 网页版之上的，它利用的是你浏览器里已经登录的网页会话，不调用任何官方 API，因此零成本。
是否支持 macOS / Linux？
核心服务 (server.js) 和油猴脚本支持跨平台。但部分内置插件（如截屏、TTS、系统通知、系统进程管理）目前使用了 Windows 的 PowerShell 接口，在 Mac/Linux 上可能需要自行适配。
本地服务安全吗？
服务仅监听 127.0.0.1（本地回环），外部设备无法访问。配合 Token 鉴权和 CORS 限制，只有你当前登录 DeepSeek 的浏览器能连接到它。
