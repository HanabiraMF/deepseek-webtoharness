# 🚀 DeepSeek WebtoHarness

赋予网页端 AI 真实的本地文件系统与 Shell 操作能力。零 API 成本，无限拓展，打造属于你的专属智能体。

## ✨ 核心特性

- **文件系统直连**：本地服务启动在哪个目录，AI 就能操作哪个目录。读取、写入、覆盖、删除、搜索一气呵成。
- **Shell 命令执行**：通过本地 Node.js 桥接服务，AI 可静默执行 CMD/PowerShell 命令。
- **18 项原生内置插件**：覆盖多语言执行、系统控制、网络诊断、文件处理等方方面面（详见下文）。
- **AI 自举拓展**：AI 可当场编写 JS 插件，或写入本地 Node.js 文件并热重载，无需修改源码。
- **防封控与自动重试**：内置高频请求冷却机制，长时间连续调用稳如老狗。
- **折叠与实时状态**：冗长的工具调用与返回结果自动折叠，配有实时状态图标。
- **安全权限掌控**：危险命令或文件覆盖需点击确认；一键开启“完全权限”进入极速模式。

## 🧰 18 项原生内置插件

本仓库自带 18 个开箱即用的服务端插件，位于 `plugins/` 目录：

| 分类 | 插件 | 说明 |
| :--- | :--- | :--- |
| **开发执行** | `python_run` | 直接运行 Python 代码或脚本，自动处理编码与缺失库。 |
| | `git_helper` | 安全执行 Git 常用操作，自动拦截高危命令。 |
| **系统控制** | `process_mgr` | 查看/查找系统进程，或强制结束指定的 PID 进程。 |
| | `notify` | 任务结束时弹出系统级桌面通知。 |
| | `screenshot` | 截取当前主屏幕并保存。 |
| | `text_to_speech` | 调用系统原生 TTS 引擎，让 AI 开口说话。 |
| | `env_info` | 一键收集硬件、版本、环境变量，快速排查问题。 |
| **网络** | `net_check` | 查询端口占用情况或列出监听端口。 |
| | `local_server` | 一键将工作区目录启动为 HTTP 静态服务器。 |
| | `wifi_info` | 获取当前 Wi-Fi 的 SSID、密码、信号等信息。 |
| | `download_file` | 从 URL 流式下载大文件到工作区。 |
| **文件处理** | `zip_tool` | 原生支持 ZIP 压缩与解压。 |
| | `pdf_tool` | 提取 PDF 纯文本，缺依赖自动 `pip install`。 |
| | `sqlite_tool` | 零依赖直连 SQLite，即时建表、查询。 |
| | `json_tool` | 格式化、压缩 JSON，或转为 CSV。 |
| | `image_tool` | 按比例缩放图片、转换格式。 |
| | `crypto_tool` | MD5/SHA 哈希计算、随机密码生成。 |
| | `qrcode_gen` | 生成二维码图片，自动处理 Python 依赖。 |

*(社区也可以自由编写插件放到 `plugins/` 下，或直接在对话中让 AI 自举生成。)*

## 🚀 快速开始

### 1. 准备环境
- 安装 [Node.js](https://nodejs.org/)（推荐 v18+）
- 安装浏览器插件 [Tampermonkey](https://www.tampermonkey.net/)
- *(可选)* 安装 Python（用于部分插件功能）

### 2. 启动本地服务
下载 `server.js` 和 `start.bat` 到**同一个目录**，双击 `start.bat` 即可启动。它会自动检测 Node.js 并打印访问 Token。关闭窗口即停止服务。

### 3. 安装油猴脚本
下载 `用户端脚本.js`，在 Tampermonkey 中新建脚本，粘贴全部代码并保存。

### 4. 连接与起飞
刷新 DeepSeek 网页，在左侧面板点击“开启模式”，填写本地服务 Token，再点击“选择目录”即可弹出系统原生的文件夹选择框。选定后前后端会同时切换到该工作区。

## 🧠 让 AI 自己长出手脚

突破现有工具的局限，实现真正的赛博自举。

### 方式 A：前端临时插件（刷新失效）
在对话中让 AI 调用 `register_plugin` 工具，直接在当前页面注册一个 JS 插件，下一轮即可使用。

### 方式 B：服务端永久插件（可持久化）
让 AI 通过 `writefile` 在 `plugins/` 下写一个 Node.js 文件，然后调用 `reload_server_plugins` 热加载。AI 就能调用系统底层 API、连接数据库，甚至操作硬件。

## ⚠️ 安全提示
本地服务与脚本会访问您的文件系统，请确保仅在安全的个人电脑上使用。对于危险操作，请保持确认弹窗开启。
