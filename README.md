# 🚀 DeepSeek WebtoHarness

赋予网页端 AI 真实的本地文件系统与 Shell 操作能力。零 API 成本，无限拓展，打造属于你的专属智能体。

## ✨ 核心特性

- **文件系统直连**：本地服务启动在哪个目录，AI 就能操作哪个目录。读取、写入、覆盖、删除、搜索一气呵成。
- **Shell 命令执行**：通过本地 Node.js 桥接服务，AI 可静默执行 CMD/PowerShell 命令。
- **31 项原生内置插件**：开发执行、系统控制、网络诊断、文件处理开箱即用（详见 `plugins/` 目录）。
- **AI 自举拓展**：AI 可当场编写 JS 插件，或写入本地 Node.js 文件并热重载，无需修改源码。
- **防封控与自动重试**：内置高频请求冷却机制，长时间连续调用稳如老狗。
- **折叠与实时状态**：冗长的工具调用与返回结果自动折叠，配有实时状态图标。
- **安全权限掌控**：危险命令或文件覆盖需点击确认；一键开启“完全权限”进入极速模式。

## 🚀 快速开始

### 1. 准备环境
- 安装 [Node.js](https://nodejs.org/)（推荐 v18+）
- 安装浏览器插件 [Tampermonkey](https://www.tampermonkey.net/)
- *(可选)* 安装 Python（用于部分扩展功能）

### 2. 启动本地服务
下载 `server.js` 和 `start.bat` 到**同一个目录**，双击 `start.bat` 即可启动。它会自动检测 Node.js 并打印访问 Token。关闭窗口即停止服务。

### 3. 安装油猴脚本
下载 `用户端脚本.js`，在 Tampermonkey 中新建脚本，粘贴全部代码并保存。

### 4. 连接与起飞
刷新 DeepSeek 网页，在左侧面板点击“开启模式”，填写本地服务 Token，再点击“选择目录”即可弹出系统原生的文件夹选择框。选定后前后端会同时切换到该工作区。

## 🧠 让 AI 自己长出手脚

突破现有工具的局限，实现真正的赛博自举。

### 方式 A：前端临时插件（刷新失效）
在对话中让 AI 调用 `register_plugin` 工具，直接在当前页面注册一个 JS 插件，下一轮即可使用。

### 方式 B：服务端永久插件（可持久化）
让 AI 通过 `writefile` 在 `plugins/` 下写一个 Node.js 文件，然后调用 `reload_server_plugins` 热加载。AI 就能调用系统底层 API、连接数据库，甚至操作硬件。

## ⚠️ 安全提示
本地服务与脚本会访问您的文件系统，请确保仅在安全的个人电脑上使用。对于危险操作，请保持确认弹窗开启。
